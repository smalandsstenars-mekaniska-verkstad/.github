# Smålandsstenars Mekaniska Verkstad

Vi driver **Valentis** — en gemensam webbportal för våra bolag. En kodbas och en
container per bolag serverar tre publika sajter, och allt innehåll, sortiment och
order hämtas ur ett delat 4D-system.

## Bolagen

### SMV Industrier — [smv.se](https://www.smv.se/)

Utvecklar, tillverkar och servar maskiner för tunnplåtsbearbetning i egen
produktion: excenterpressar, valsmatarverk, riktverk och hasplar. Bygger också
ihop maskinerna till kompletta produktionslinjer och förlänger livslängden på
befintlig utrustning genom ombyggnad med moderna styrsystem.

### SMV Verktyg — [verktyg.smv.se](https://verktyg.smv.se/)

Levererar skärande verktyg och processvätskor till industrin, från noggrant
utvalda tillverkare. Sortimentet täcker hela produktionskedjan — verktyg,
automation, mätteknik och vätskehantering.

### SVEA Maskiner — [svea.no](https://svea.no/)

Samma erbjudande på den norska marknaden, med leverantörer som Iscar, TaeguTec
och Matrix. Sajten körs på norska mot samma plattform och samma backend som de
svenska.

## Här på GitHub

Plattformen är uppdelad i ett arkiv per del — 4D-backend, Angular-frontend,
proxy, containrar och provisionering — och de flesta är privata. Det här arkivet
innehåller organisationsgemensamma filer, bland annat den heartbeat som bevakar
plattformen utifrån ([README](https://github.com/smalandsstenars-mekaniska-verkstad/.github#heartbeat)).
